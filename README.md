# HRM Lokal

Aplikasi manajemen SDM satu halaman berbasis HTML, CSS, dan JavaScript. Tidak memerlukan server, framework, maupun database terpisah.

## Menjalankan

Unduh atau clone repository, lalu buka `index.html` pada browser modern.

## Fitur

- Dashboard dengan ringkasan karyawan, training, kompetensi, dan pengingat kontrak PKWT.
- Manajemen karyawan: profil, identitas, kontak, departemen, jabatan, status, dan catatan; tambah, edit, hapus, cari, dan ekspor CSV.
- Pencatatan metadata kontrak PKWT/PKWTT.
- Pencatatan training, peserta, penyelenggara, durasi, status, dan hasil.
- Matriks penilaian kompetensi skala 1–5.
- Simpan otomatis di localStorage browser.
- Backup dan restore data JSON.
- Tampilan responsif untuk desktop dan ponsel.

## Catatan penyimpanan dan privasi

Data hanya tersimpan di browser/perangkat yang digunakan dan tidak tersinkron ke perangkat lain. Menghapus data browser dapat menghapus data HRM. Gunakan menu **Backup data** secara berkala dan simpan file backup di lokasi yang aman. Jangan menyimpan data sensitif tanpa kebijakan akses dan perlindungan yang memadai. Aplikasi ini tidak mengunggah atau menyimpan berkas kontrak; catatan kontrak hanya berisi metadata. Pastikan format dan proses dokumen ketenagakerjaan ditinjau sesuai peraturan yang berlaku.
